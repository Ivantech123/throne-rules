# Throne route profile

`cudy-rules.json` is a Throne route profile with the same split-routing rules as the home router.
In Throne: Routing → Routing Settings → New → Advanced → Import JSON, or set this file's raw URL as the profile's remote URL so it updates by itself.

Raw URL: https://raw.githubusercontent.com/Ivantech123/throne-rules/main/cudy-rules.json
