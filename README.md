# Throne route profile

`cudy-rules.json` is a Throne route profile with the same split-routing rules as the home router.

## Add it to Throne 1.4+

One click: open this link (or copy it and press Ctrl+V in Throne's main window):

```
throne://remoteroute/aHR0cHM6Ly9yYXcuZ2l0aHVidXNlcmNvbnRlbnQuY29tL0l2YW50ZWNoMTIzL3Rocm9uZS1ydWxlcy9tYWluL2N1ZHktcnVsZXMuanNvbiPQmtCw0Log0LTQvtC80LAgKEN1ZHkp
```

Or by hand: Settings → Routing Settings → Route tab → New → Remote profile, URL below, tick Auto update.

Raw URL: https://raw.githubusercontent.com/Ivantech123/throne-rules/main/cudy-rules.json

For scheduled updates also turn on Settings → Basic Settings → Subscription → Routing profiles auto update (advanced mode).
